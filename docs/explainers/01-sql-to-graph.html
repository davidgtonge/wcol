THE CONSTRAINTS

Designed around the limits.

These aren't implementation details added afterward. They shape the execution graph.

01 / STREAMS
⇢

Data moves in bounded frames.

WCS frames have a 64 KiB payload cap. Mailboxes and backpressure prevent a slow consumer from forcing unbounded buffering upstream.

02 / PLACEMENT
⫶

One logical graph, many nodes.

The graph describes computation. Placement assigns fragments to execution nodes, while the host handles streams and I/O.

03 / MEMORY
▤

Spill is part of execution.

Hash aggregation flushes sorted runs when the working set grows too large, then merges those runs without keeping every group in memory.
