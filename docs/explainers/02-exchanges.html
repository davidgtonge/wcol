THE DESIGN RULES
The exchange is a correctness boundary.
Identical source data. Different routing contracts. Different algorithms—and different guarantees.
01 / HASH
⌗
Co-location, not ordering.
Hash partitioning guarantees equal keys meet at one reducer. It does not make partitions globally ordered. Hashing a global sort and concatenating the output is incorrect.
02 / RANGE
↕
Ordering is a partition invariant.
Range partitioning sends adjacent sort keys to ordered, non-overlapping partitions. Local sorts can then be concatenated in partition order without another full sort.
03 / TOP K
↑
Send candidates, not every row.
For a plain ORDER BY … LIMIT K, each scanner can keep its best K. A final Top K over those candidates is exact, without all-to-all repartitioning.
